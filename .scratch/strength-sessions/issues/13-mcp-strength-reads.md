# 13: MCP strength reads

**What to build:** Claude can list exercises and templates, read strength history (sets by session for an exercise or a date range), and see strength sessions, with their template and a summary of the log, in the existing session read. No tool can create or edit logged sets or mark a session completed.

**Status:** done

- [x] A tool returns strength history for an exercise or date range
