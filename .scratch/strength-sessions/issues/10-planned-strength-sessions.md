# 10: Planned strength sessions in the plan

**What to build:** A planned session can be a strength session with a kind and a template, with the same date, phase, status and revision as a run. It shows in the week view and on Today with a Start action that opens the logger linked to that planned session. Finishing marks it completed. A planned session with no finished linked log once its day has passed is missed, and a log started from a different template that day, or with no plan link, is unplanned. Completion never needs Garmin data. Strength cards drag between days like run cards.
