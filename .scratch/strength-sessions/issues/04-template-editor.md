# 04: Template editor

**What to build:** Create a template from scratch or edit an existing one in the app: name, kind, adding, removing and reordering exercise slots, sets, rep range or hold time, rest time, per-side, and superset grouping of consecutive slots. Editing is a deliberate action by the runner, not a proposal.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] A new template can be created and then appears in the Strength tab list
- [ ] An existing template can be edited and the changes persist
- [ ] Exercises can be picked from the library or created by typing a new name with the duplicate check
- [ ] Superset groups can be set only across consecutive slots
- [ ] Templates hold no target weight
