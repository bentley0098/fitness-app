# 11: Weekly strength line and Garmin duration and heart rate

**What to build:** The week summary gets a separate line showing strength sessions finished versus planned, with run kilometres and run session counts unchanged. A Garmin strength activity on the same date, when present, supplies duration and heart rate to the strength log; its absence never blocks completion. Strength does not affect the engine verdict or weekly run volume.
