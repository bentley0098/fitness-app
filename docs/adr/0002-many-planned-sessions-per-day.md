# A date holds many planned sessions, and moving a session no longer swaps

The plan used to allow one session per date, so adding needed an empty day and moving onto an occupied day swapped the two. Strength work (ankle physio before a run, gym on a run day) needs several sessions on one date, so any number of sessions of any kind may share a date and a move simply relocates one session. Keeping a one-run-per-day rule to preserve the swap was rejected as needless coupling; swapping two sessions is now two moves.
