# Strength sets are entered by hand, not ingested from Garmin

The spec's "no manual entry" principle holds for runs, but strength reps and weights are typed in by the runner during the session. The watch's rep and weight detection is unreliable, so the strength log is the source of truth. A matching Garmin activity on the same day is linked only for duration and heart rate, and a session with no watch data still counts as completed.
